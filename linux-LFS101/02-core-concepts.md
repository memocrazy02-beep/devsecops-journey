# Linux Terminology

## Kernel
Es el nucleo del sistema es el intermediario entre las aplicaciones y el hardware se encarga de administrar los recursos del hardware para que las aplicaciones puedan usar los recursos de una manera eficiente y segura

**El kernel administra:**
- CPU
- RAM
- ALMACENAMIENTO
- PERIFERICOS (entrada/salida)
- RED
- SEGURIDAD Y PERMISO DE ACCESO A TODOS LOS ANTERIORES

**Ejemplo Real:**
Cuando abres firefox es el kernel el que se encarga de los procesos para abrirlo, el kernel le dice ala cpu que abra un nuevo proceso y lo ejecuta

## Distribution (Distro)
Es el kernel de linux pero empaquetado junto con software adicional como gestor de paquetes,desktop enviroment,herramientas y apps y varia dependiendo de la distro

**Ejemplos de distribuciones:**
-Ubuntu,Fedora,Arch,Kali,Gentoo y muchas otras mas
