# Linux Terminology

## Kernel
Es el nucleo del sistema es el intermediario entre las aplicaciones y el hardware se encarga de administrar los recursos del hardware para que las aplicaciones puedan usar los recursos de una manera eficiente y segura

**El kernel administra:**
- CPU
- RAM
- ALMACENAMIENTO
- PERIFERICOS (entrada/salida)
- RED
- SEGURIDAD Y PERMISO DE ACCESO A TODOS LOS ANTERIORES

**Ejemplo Real:**
Cuando abres firefox es el kernel el que se encarga de los procesos para abrirlo
